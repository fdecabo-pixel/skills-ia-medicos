# Configura tu cierre de sesión

> El pase de guardia entre una conversación con tu agente y la siguiente.

## Qué es

Una skill configurable. Monta los archivos de memoria de tus proyectos y te deja una skill propia de «cierre» que, al acabar de trabajar, apunta qué se hizo, qué se decidió y cuál es el siguiente paso.

## Para qué sirve

- Retomar un proyecto días después sin volver a explicarlo.
- Que lo que el agente aprende de cómo te gusta trabajar no se pierda.
- Compartir la misma memoria entre Claude Code y Codex.

## Por qué es importante

Un agente empieza cada conversación en blanco, como un compañero que entra de guardia sin pase. Lo que no queda escrito se pierde, y lo acabas repitiendo. Un cierre breve al terminar ahorra la explicación al empezar.

## Qué necesitas

- Claude Code o Codex.
- Saber en qué carpeta trabajas (si no lo tienes claro, empieza por `ordena-tu-espacio-de-trabajo`).

## Cómo se usa

Una vez instalada, abre una conversación nueva con tu agente y pídelo con tus palabras. Por ejemplo:

- «El agente no se acuerda de lo que hicimos ayer.»
- «Configura un cierre del día.»

## Qué te deja

Un archivo de estado en cada proyecto, una carpeta de memoria general con su índice y una skill `cierre`.

## Límites y garantías

- En la memoria no se guardan claves ni datos de pacientes.
- Añade líneas a las instrucciones generales de tu agente sin borrar las que tengas.
