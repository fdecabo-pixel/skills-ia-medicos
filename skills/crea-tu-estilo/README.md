# Crea tu skill de estilo

> Para que tu agente redacte correos y mensajes con tu voz, no con la de una IA.

## Qué es

Una skill configurable. No trae el estilo de nadie: analiza cómo escribes tú, a partir de tus correos enviados o de 15-20 textos tuyos, y construye tu propia skill de estilo.

## Para qué sirve

- Responder correos con tu saludo, tu despedida y tu manera de decir las cosas.
- Que los borradores del agente necesiten pocos retoques.
- Distinguir el tono según a quién escribes: compañeros, instituciones, industria.

## Por qué es importante

Un texto escrito por una IA se reconoce: fórmulas de cortesía que tú no usas, frases demasiado redondas. Cuando un compañero o una institución recibe un correo así, lo nota. Con tu skill de estilo el agente hace el borrador y lo que firmas sigue sonando a ti.

## Qué necesitas

- Claude Code o Codex.
- El conector de correo de tu agente (lo que le permite leer tu Gmail u Outlook), o bien 15-20 textos tuyos.
- Unos 20-30 minutos.

## Cómo se usa

Una vez instalada, abre una conversación nueva con tu agente y pídelo con tus palabras. Por ejemplo:

- «Quiero que escribas como yo.»
- «Crea mi skill de estilo a partir de mis correos.»

## Qué te deja

Una skill `estilo-<tu nombre>` con tres archivos: las reglas de tu voz, ejemplos reales anonimizados y las cosas que nunca dirías.

## Límites y garantías

- Si escribes a pacientes desde esa cuenta, no lee el correo: trabaja solo con textos que tú elijas y limpies antes.
- Deja siempre un borrador; no envía nada.
- Las prohibiciones («nunca…») las confirmas tú: no las deduce por su cuenta.
