# Vigila tu tema cada mes

> Lo que se publica sobre tu tema, cada mes, con cada referencia comprobada.

## Qué es

Una skill configurable. Diseña contigo una búsqueda en PubMed sobre tu tema, la valida y te deja una skill propia que la repite cada mes y te entrega solo lo nuevo.

## Para qué sirve

- Estar al día de una enfermedad, una técnica o un grupo de fármacos.
- Preparar la sesión bibliográfica del servicio.
- No depender de que alguien te reenvíe el artículo.

## Por qué es importante

Nadie puede leer todo lo que se publica de su especialidad. Las alertas automáticas mandan decenas de títulos sin filtrar, y un resumen hecho por una IA sin verificar puede incluir artículos que no existen o afirmar más de lo que el estudio sostiene. Aquí la búsqueda es siempre la misma, cada referencia se comprueba y el resumen se redacta solo con el título y el resumen de PubMed, para que lo revises tú.

## Qué necesitas

- Claude Code o Codex.
- Nada más: usa el conector de PubMed si lo tienes y, si no, el servicio público de consulta de PubMed, que no pide clave.

## Cómo se usa

Una vez instalada, abre una conversación nueva con tu agente y pídelo con tus palabras. Por ejemplo:

- «Quiero estar al día de mi tema.»
- «Monta una alerta bibliográfica sobre…»

## Qué te deja

Una skill `novedades-<tu tema>` con la estrategia de búsqueda fijada, un registro de lo ya revisado para no repetir y una carpeta con cada entrega.

## Límites y garantías

- Entrega material para que lo revises tú; no envía ni publica nada.
- Si un artículo no tiene resumen en PubMed, no inventa su hallazgo.
- Para que salte sola hay que programarla; la skill explica cómo.
