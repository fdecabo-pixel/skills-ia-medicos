# Opera tu campus virtual

> Subir material y preparar tareas en Moodle sin hacerlo clic a clic.

## Qué es

Una skill configurable para docentes. Explora tu campus contigo, prueba las tareas que más repites y te deja una skill propia con las recetas que han funcionado en tu Moodle.

## Para qué sirve

- Subir el material de una clase.
- Crear una tarea con su fecha y sus instrucciones.
- Dejar redactado un aviso o preparada una corrección.

## Por qué es importante

Las tareas del aula virtual son mecánicas y roban tiempo de preparar la clase. Pero un campus no perdona errores: un aviso publicado llega por correo a todo el curso, y una nota guardada puede notificarse al estudiante. Por eso la skill separa lo que el agente prepara de lo que solo tú publicas.

## Qué necesitas

- Claude Code o Codex.
- Una forma de que el agente maneje el navegador (la skill explica las dos opciones).
- Permisos de edición en tus cursos y, a ser posible, un curso de pruebas.

## Cómo se usa

Una vez instalada, abre una conversación nueva con tu agente y pídelo con tus palabras. Por ejemplo:

- «Sube esto al campus virtual.»
- «Monta una skill para mi aula virtual.»

## Qué te deja

Una skill `campus-<tu centro>` con las recetas probadas en tu campus y sus reglas de seguridad.

## Límites y garantías

- Todo lo nuevo se crea oculto: lo muestras tú.
- No envía avisos ni mensajes a estudiantes, no escribe calificaciones y no borra nada.
- La sesión la inicias tú; el agente no maneja tu contraseña.
- Está pensada para Moodle.
