# Monta tu plantilla de documentos

> Tus guías, protocolos y apuntes en PDF, siempre con tu imagen y revisados.

## Qué es

Una skill configurable. Monta una plantilla con tu logo, colores y pie, y te deja una skill propia que convierte un texto en un PDF maquetado y lo revisa antes de dártelo.

## Para qué sirve

- Hojas de consejos para pacientes.
- Protocolos del servicio y apuntes de clase.
- Propuestas y documentos que entregas a otros.

## Por qué es importante

Un documento que das a un paciente o a un compañero lleva tu nombre. Maquetarlo a mano cada vez consume tiempo y sale distinto. Y pedirle un PDF a una IA sin revisión deja pasar tablas cortadas, títulos huérfanos o un nombre comercial que no querías. Aquí la revisión es parte del proceso, no un paso opcional.

## Qué necesitas

- Claude Code o Codex.
- Chrome o Edge actualizado y Python 3, un programa gratuito que el agente usa por debajo.
- Tu logo y tus colores, si los tienes.

## Cómo se usa

Una vez instalada, abre una conversación nueva con tu agente y pídelo con tus palabras. Por ejemplo:

- «Quiero que mis documentos salgan con mi logo y colores.»
- «Monta una plantilla para mis PDF.»

## Qué te deja

Una carpeta con tu plantilla, un guion que genera el PDF, tu lista de términos vetados y una skill `documento-<tu marca>`.

## Límites y garantías

- La fecha de revisión la das tú en cada documento; nunca la pone por defecto.
- No sustituye la revisión clínica del contenido.
